## Descripcion de cada Problema

### Problema 1: Evaluación de Polinomio (x+1)^n
Este programa solicita al usuario un número entero no negativo `n` y un valor `x`. Su objetivo es calcular y mostrar los coeficientes del polinomio `(x+1)^n`, evaluar paso a paso la función para el valor de `x` dado, y finalmente medir el tiempo de ejecución del proceso. Los resultados y el tiempo de ejecución se guardan en un archivo de texto
* **Lenguajes utilizados:** C++ y Java.

### Problema 2: Validador de Notación FEN 
Este programa se encarga de recibir una cadena de texto y validar si está correctamente escrita en notación FEN (Forsyth-Edwards Notation), la cual se utiliza para representar posiciones en un tablero de ajedrez. El algoritmo verifica rigurosamente que la cadena contenga los 6 campos reglamentarios (piezas, turno, enroque, peón al paso, reloj y número de movimientos) y que la distribución de las filas sume exactamente 8 casillas.
* **Lenguaje utilizado:** Java.

### Problema 3: Traductor de Palabras Reservadas
Este programa abre y lee un archivo de código fuente llamado `codigo.c`. Recorre su contenido en memoria dinámica para identificar palabras reservadas propias del lenguaje C y muestra por consola la traducción al español de cada una de las palabras reservadas que logre detectar dentro del código analizado.
* **Lenguaje utilizado:** C.
